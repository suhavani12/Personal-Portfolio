# Personal Portfolio

A responsive portfolio website for **Suhavani Neelam**, B.Tech Computer Science and Engineering student.

## Sections
Home, About, Education, Skills, Projects, Achievements, Contact

## Features
- Project filter buttons (All / AI / Web / Other)
- Dark and light mode
- Contact form with validation
- Smooth scrolling navigation
- Works on mobile and desktop

## Built With
HTML5, CSS3, Bootstrap 5, JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in a browser.

## Files
- `index.html` - page content
- `style.css` - styles
- `script.js` - project filter, theme toggle, form validation
